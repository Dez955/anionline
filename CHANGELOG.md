# Історія версій AniTube для Lampa

Номер версії позначає окрему ітерацію. Наступна ітерація після 1.8.4 отримує 1.8.5; не перевикористовувати номер завершеної ітерації. Зберігати попередній код перед новими змінами й додавати запис сюди. Публікація бети та перенесення в основний — окремі статуси, номер локального файла не означає, що його вже опубліковано.

## 1.8.4 — 02.11.2026 — опублікована бета

- Продовження кандидата 1.8.3; його код збережено в `dev/archive/2026-11-02/1.8.3/`.
- Уточнені повідомлення Moon: відсутній маршрут Worker, неправильний доступ до проксі та помилка отримання сторінки плеєра розрізняються. Помилка HTTP 400 Moon більше не пояснюється необхідністю оновлення Worker.
- Користувач окремо й прямо дозволив браузерний User-Agent для перевірки Moon. Запити виконалися: перша й друга серії Morys на moonanime.net та перша на відомому домені moonanime.art повернули HTTP 400 / `<h1>500</h1>`. Конфігурація/потік не отримані, відтворення Moon не підтверджене. Непотрібна постійна підміна User-Agent в код не додавалась.
- Синтаксичні перевірки, регресії метаданих/парсера/Worker та сценарії перемикання Ashdi → Moon на штучних відповідях пройшли. Це не доказ відтворення Moon на сайті або ТВ.
- За прямою командою користувача 1.8.4 опублікована для онлайн-тесту як anitube-beta.js. Основний файл залишається 1.8.2. Код Worker опублікований для ручного оновлення, сам Worker не розгорнуто. Moon залишається експериментальним.

## 1.8.3 — 02.11.2026 — локальний кандидат, не публікувався

- Картки серій: дата прем’єри ДД.ММ.РРРР окремим рядком, команда та плеєр; визначення максимальної якості з доступного API/HLS-мастеру.
- Збережені варіанти команд і плеєрів AniTube; додано окремий вибір плеєра.
- Експериментальний статичний розбір конфігурації Moon без виконання JS; новий маршрут /moon у локальному коді Worker.
- Ashdi перевірено живими запитами; Moon — тестовими конфігураціями. Запит із браузерним User-Agent тоді був відхилений автоматичною перевіркою і не виконався; окремий явний дозвіл та результат — у 1.8.4.
- Код: `dev/archive/2026-11-02/1.8.3/anitube.js`; докладні результати: `dev/research-1.8.3.md`.

# AniTube beta 1.8.15 — LG / Samsung

Основний файл лишається 1.8.2. Бета містить незалежний AnimeOn, короткі назви серій, прибирання статусів готовності та виправлення меню якості Moon.

1. Залиш один активний AniTube. Адреса: https://dez955.github.io/a.js або https://dez955.github.io/anionline/anitube-beta.js?v=1.8.15
2. Повністю перезапусти Lampa. Налаштування → AniTube має показати «Версія 1.8.15».
3. Для AnimeOn обов'язково онови Worker: відкрий https://raw.githubusercontent.com/Dez955/anionline/main/home-proxy/cloudflare-worker.js , скопіюй код. Cloudflare → Workers & Pages → anitube-proxy → Edit code → заміни код → Deploy. ACCESS_KEY та EMBED_URL залиш без змін. Без цього новий AnimeOn на ТВ поверне 404.
4. Перевір AnimeOn: пошук, озвучення, серію. Перевір Moon: підпис якості, ручний вибір, короткі назви серій і відсутність статусу готовності.

Пошук, озвучення й серії AnimeOn читаються з API самого сайту, без агрегатора. Поки підтримуються варіанти Ashdi. Список серій оновлюється при відкритті. Для Moon/інших виправлень інтерфейсу нові маршрути Worker не потрібні.

Місцеві регресії та справжні відповіді AnimeOn пройшли перевірку. На фізичних LG/Samsung новий код ще не перевірено. Makhno не змінювався. Повідомлення «Таймкоды загружены» має невстановлене походження; його видалення не підтверджене.

# ДубльUA beta 2.0.25 — автоматичний підбір джерел (23.11.2026)

> Бета-адреса для тесту на телевізорі: `https://dez955.github.io/anionline/anitube-beta.js?v=2.0.25`. Додай цю довгу адресу в Lampa, вимкни попередній екземпляр ДубльUA/A і повністю перезапусти Lampa. У цій версії автопошук визначає тип картки й ставить відповідні джерела першими; приховані джерела пропускаються; автоматичний перехід за замовчуванням увімкнений і чекає до 7 секунд на джерело. У Налаштуваннях → ДубльUA його можна вимкнути й надалі вибирати джерело вручну. Worker не змінювався й повторний Deploy не потрібен. Тип картки визначається з метаданих Lampa, тому варто перевірити окремо аніме, звичайний фільм, серіал і дораму. На фізичному ТВ ця версія ще не перевірена.

> **2.0.24 — клієнтам не потрібен ключ Worker.** Опублікована бета: `https://dez955.github.io/anionline/anitube-beta.js?v=2.0.24`. Спершу онови Worker: Cloudflare → Workers & Pages → `anitube-proxy` → Edit code → заміни код вмістом [home-proxy/cloudflare-worker.js](home-proxy/cloudflare-worker.js) → Deploy. **Не змінюй** поточні `ACCESS_KEY`, `EMBED_URL` і KV `SYNC` під час цього Deploy. Секрет `ACCESS_KEY` використовується лише для Worker → сервісу на Koyeb і має збігатися з `ANITUBE_ACCESS_KEY` там. Після Deploy додай довгу адресу бети в Lampa; ключ у налаштуваннях плагіна для вбудованого Worker вводити не потрібно. Фіксовані маршрути Worker відкриті для публічного використання; довільні адреси як проксі не приймаються. Основний `anitube.js` і коротка адреса A не змінюються.

# Попередні нотатки бети

> Нижче збережено історію тестування старіших версій. Поточні кроки й адреса вказані вище.

Увімкни **Показувати російські джерела**, відкрий картку аніме → **ДубльUA** → **Джерело** → **Kodik (YummyAnime / Jut-su)**. Перевірений приклад: «Кіберпанк: Бегущие по краю», 2 сезон — 10 серій, перша відтворюється через HLS 720p. Для Samsung/LG онови Worker: Cloudflare → Workers & Pages → `anitube-proxy` → Edit code → заміни код вмістом [home-proxy/cloudflare-worker.js](home-proxy/cloudflare-worker.js) → Deploy. Значення `ACCESS_KEY`, `EMBED_URL` і сховище `SYNC` не змінюй. 1080p є лише коли цю якість віддає сам Kodik; у перевіреній серії доступно до 720p. На фізичному ТВ ще не перевірено. Основний файл `anitube.js` 1.8.19 і коротка адреса A не змінені.

> **2.0.19 (опублікована бета): виправлення «кракозябр» у повідомленнях.** Адреса: `https://dez955.github.io/anionline/anitube-beta.js?v=2.0.19`. Причина: Worker у Cloudflare потрапив у неправильному кодуванні й віддавав зіпсований український текст. **Оновити Worker (потрібен новий Deploy):** Cloudflare → Workers & Pages → `anitube-proxy` → Edit code → заміни весь код вмістом [home-proxy/cloudflare-worker.js](home-proxy/cloudflare-worker.js) → Deploy (змінні `ACCESS_KEY`, `EMBED_URL`, KV `SYNC` не чіпати). Тепер код Worker суто ASCII, тож вставка з будь-якого місця його не зіпсує. Плагін також сам лікує зіпсований текст від старого Worker. Увага: доступ з Cloudflare до ДорамиUA переривчастий; надійно вона працює лише з української адреси (Android, приставка). Основний `anitube.js` 1.8.19 і коротка адреса A (2.0.9) без змін.

> **2.0.18 (опублікована бета): «Пошук» з вибором назв, запасний шлях ДорамиUA, без KinoPub.** Адреса: `https://dez955.github.io/anionline/anitube-beta.js?v=2.0.18`. Що нового: (1) чип «Пошук» відкриває список назв картки, щоб нічого не вводити вручну («Ввести вручну» лишився останнім пунктом); (2) якщо в налаштуваннях вписана адреса приставки, а вона мовчить, ДорамаUA сама йде через Worker; (3) KinoPub прибрано повністю. Worker не змінювався, повторний Deploy не потрібен (BambooUA вже працює з 2.0.17). Основний `anitube.js` 1.8.19 і коротка адреса A (2.0.9) без змін.

> **2.0.17 (опублікована бета): нове джерело BambooUA** (українська студія дорам: дубляж і субтитри, приставка не потрібна). Адреса: `https://dez955.github.io/anionline/anitube-beta.js?v=2.0.17`. **Щоб BambooUA працювало на Samsung/LG, оновити Worker:** Cloudflare → Workers & Pages → `anitube-proxy` → Edit code → встав увесь [home-proxy/cloudflare-worker.js](home-proxy/cloudflare-worker.js) → Deploy (змінні `ACCESS_KEY`, `EMBED_URL`, KV `SYNC` не чіпати). На Android Worker не потрібен. Перевірити: дорама → Джерело → BambooUA → «Дубляж» або «Субтитри»; серії «для підписників» плагін пропускає, бо на сайті вони платні. Чи пускає сайт адреси Cloudflare, ще не відомо: якщо на ТВ пише помилку HTTP 424, дай знімок. Основний `anitube.js` 1.8.19 і коротка адреса A (2.0.9) без змін.

> **2.0.16 (опублікована бета): плагін тепер «ДубльUA», мітки субтитрів за реальними файлами.** Адреса після публікації: `https://dez955.github.io/anionline/anitube-beta.js?v=2.0.16`. ## Нове у 2.0.11

- Налаштування → AniTube → перший пункт **«Показати / сховати джерела»**. Натискання на джерело перемикає «Показувати / Приховано». Приховане прибирається з меню й автоматичного пошуку. Збережені вибори не видаляються.
- Відомі збережені сторінки AniTube, зокрема з дзвіночка, відкриваються без повторного пошуку та очікування додаткових назв TMDB/AniList.
- Очікування картинок/дат серій TMDB обмежене 500 мс замість 5 секунд; за повільної відповіді вони можуть тимчасово не показуватися.
- 20 актуальних офлайн-тестів пройшли. Швидкість на фізичному Samsung ще треба перевірити. Для 2.0.11 нового Deploy Worker не потрібно, серверний код не змінено.

## Що додано

- DoramaUA у меню «Джерело»: українське озвучення, українські субтитри й автосубтитри окремо. Російські варіанти — лише за перемикачем РОС.
- Фактичні серії кожного перекладу беруться з плеєра сайту. Перед запуском перевіряється відповідність тайтлу, сезону, серії й озвучення. Короткі назви на кшталт «Мо Лі» знаходяться за повним збігом.
- На Samsung/LG для Davidog використовується native HLS; список наступних серій завантажується ліниво. Стеження лишається тільки для аніме на AniTube.

## Що зробити на Samsung/LG

1. Якщо Worker ще не має `/dorama/player`, Cloudflare → Workers & Pages → `anitube-proxy` → Edit code → встав увесь [home-proxy/cloudflare-worker.js](home-proxy/cloudflare-worker.js) → Deploy. Змінні `ACCESS_KEY`, `EMBED_URL` та KV `SYNC` не змінюй. Бот не потребує оновлення, PR/Merge не потрібні. На чинному Worker власника маршрут уже є; повторний Deploy сам по собі не усуне регіональну відмову нижче.
2. Lampa → Налаштування → Плагіни: вимкни A та інші дублікати AniTube, додай або увімкни довгу бета-адресу вище. Повністю закрий і знову відкрий Lampa.
3. Відкрий дораму → AniTube → Джерело → DoramaUA → Озвучення. Перевір запуск, український звук/субтитри, наступну серію та повернення назад.
4. Для повернення на робочу версію вимкни бету, увімкни A й перезапусти Lampa.

## Що перевірено

19 актуальних офлайн-тестів пройшли. Із Mac пройдено живий шлях пошук → тайтл → локально виконаний Worker → точна озвучка/серія → HLS для «Військового кухаря», «Мо Лі» й «Чаші весни». Окремо перевірено відеосегмент H.264/AAC та український WEBVTT.

**Через чинний Cloudflare Worker 08.11 підтверджена регіональна відмова DoramaUA.** Сам маршрут відповідає HTTP 200, але тіло — повідомлення про регіон; новий парсер правильно відхилив його. Отже, хмарний шлях для Samsung/LG наразі не підтвердив працездатність. Повторний Deploy не обходить обмеження країни. Android напряму або вже налаштована домашня приставка — інші наявні шляхи; їх на фізичному пристрої з 2.0.10 ще не перевірено.

Якість і кількість перекладених серій залежать від конкретної доріжки: наявність дорами не означає, що всі серії вже озвучені українською. Публікація бети не означає підтвердження відтворення на ТВ.

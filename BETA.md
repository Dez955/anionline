# AniTube beta 1.8.5 — онлайн-тест

Основний плагін — 1.8.2. Бета — 1.8.5. Це тестовий випуск: дати, максимальна якість, команди й окремий вибір плеєра AniTube. У 1.8.5 розширено підтримку форматів Moon і явних списків якостей; вибирається найбільша доступна роздільність. Moon експериментальний; справжній сервер під час перевірки повертав HTTP 400 / 500. Працездатність Moon на ТВ не підтверджена.

## Встановити бету

1. Lampa → Налаштування → Розширення. Вимкни або видали попередній запис AniTube, щоб дві версії не запускалися одночасно.
2. Додай плагін: https://dez955.github.io/anionline/anitube-beta.js?v=1.8.5
3. Повністю перезапусти Lampa.
4. Відкрий аніме → AniTube. Під час запуску серії повідомлення повинно містити AniTube v1.8.5.
5. Перевір дату у форматі ДД.ММ.РРРР, команду/плеєр і позначку максимальної якості там, де її вдалося визначити. Якість може з’явитися через кілька секунд; її відсутність не означає 480p.

Адреса стандартного проксі й ключ уже вбудовані. Для перевірки звичайного AniTube не потрібно заповнювати адресу приставки.

## Moon на Samsung / webOS

Для дат, карток, якості та Ashdi оновлення Worker не потрібне. Для Moon на ТВ потрібен маршрут /moon. Якщо ти вже вставив Worker з 1.8.4, для цього аніме з /iframe його достатньо; для посилань /vod потрібен новий код:

1. Відкрий код: https://raw.githubusercontent.com/Dez955/anionline/main/home-proxy/cloudflare-worker.js
2. Cloudflare → Workers & Pages → anitube-proxy → Edit code.
3. Заміни код цілком на вміст файла вище й натисни Deploy. Наявні ACCESS_KEY і EMBED_URL залиш без змін.
4. У плагіні обери команду, тоді Плеєр → Moon. Кількість серій може відрізнятися від Ashdi.

Цей файл Worker опублікований як код для ручного оновлення. Cloudflare автоматично не оновлюється. Наявність маршруту не усуває відмову самого Moon.

## Повернути основну версію

Заміни адресу бети на https://dez955.github.io/anionline/anitube.js?v=1.8.2 і перезапусти Lampa. Не залишай обидва плагіни активними.

## Перевірено

Синтаксис плагіна й Worker; тести метаданих/парсера та дозволених адрес Worker; перемикання Ashdi/Moon на тестових відповідях. Раніше живий стенд отримав справжні серії й потік Ashdi. Тестові відповіді Moon не доводять справжнє відтворення. Дати TMDB у стенді підроблені; вигляд, пульт і відтворення на ТВ перевіряє користувач.

# AniTube beta 2.0.9 — що змінилось і що зробити

Основний файл лишається 1.8.19. Бета 2.0.8 уже опублікована; 2.0.9 — локальна, **ще не опублікована**.

**2.0.9:** напис версії показується один раз за запуск Lampa; чип «Стеження N» зі сторінок прибрано (список — зірка в шапці Lampa й дзвіночок); **DoramaUA прибрано**. Повторний Deploy Worker для 2.0.9 не потрібен, якщо вже вставлено код 2.0.8.

**З 2.0.8:** джерела **Eneyida** і **Klon UA** (чип «Джерело»); **Makhno прибрано** (його сервер мертвий); розділ Налаштування → AniTube → «UAflix — акаунт».

**Щоб Eneyida і Klon UA працювали на Samsung/LG** (на Android вони працюють і без цього):
1. Cloudflare → Workers & Pages → `anitube-proxy` → Edit code → встав увесь код `home-proxy/cloudflare-worker.js` → Deploy. Змінні (`ACCESS_KEY`, `EMBED_URL`, `SYNC`) не чіпай.

**Щоб UAflix працював на ТВ без приставки (твій власний безкоштовний акаунт на uafix.net) — вхід такий самий, як у плагіні UAKino:**
1. GitHub → відкрий `https://github.com/Dez955/my-smart-bot/compare/main...claude/anitube-uafix-login?expand=1` → Create pull request → Merge. Koyeb перезапуститься (~1 хв). (Змінних на Koyeb додавати не треба.)
2. Cloudflare Worker оновлено кроком вище (там теж є вхід).
3. В Lampa: Налаштування → AniTube → «UAflix — акаунт» → введи «Логін» і «Пароль». Вхід виконається сам; на кнопці має з'явитися «Вийти» і «Вхід виконано (твій логін)».
4. Відкрий серіал через джерело UAflix. Якщо й далі лише трейлер — скажи, що саме показало (і чи писало «Вхід виконано»).

Пароль зберігається в Lampa на цьому пристрої й іде лише на твій Worker і твій бот (не на чужий сервер).

---

Локальна **1.8.18** ще НЕ опублікована. Для Ashdi на ТВ повернуто адаптивний старт, пропускається повторний парсер Lampa та прибрано очікування метаданих; ручні якості залишаються. Worker не потребує змін. Нижче — інструкція опублікованої 1.8.17.

# AniTube beta 1.8.17 — LG / Samsung

Основний файл лишається 1.8.2. Worker уже оновлений; повторний Deploy для цієї версії не потрібен.

1. Залиш один активний AniTube: https://dez955.github.io/a.js або https://dez955.github.io/anionline/anitube-beta.js?v=1.8.17
2. Повністю перезапусти Lampa. У налаштуваннях AniTube перевір версію 1.8.17.
3. При натисканні ОК має одразу з'явитися «AniTube v1.8.17 · Серія N». При наступному відео/автопереході версія з'являється знову; початковий запуск не дає дубля.
4. Перевір швидкість запуску Ashdi в AniTube й AnimeOn, наступну серію, пульт і повернення назад. На ТВ старт більше не чекає сусідні серії; Ashdi явно використовує native HLS. Moon зберігає програмний режим.

Регресії, повний мережевий шлях Ashdi й API AnimeOn перевірені; нове відтворення на фізичних LG/Samsung ще не перевірено. Повідомлення «Таймкоды загружены» досі має невстановлене походження. Makhno не змінювався.

# AniTube beta 1.8.17 — LG / Samsung

Основний файл лишається 1.8.2. Worker уже оновлений; повторний Deploy для цієї версії не потрібен.

1. Залиш один активний AniTube: https://dez955.github.io/a.js або https://dez955.github.io/anionline/anitube-beta.js?v=1.8.17
2. Повністю перезапусти Lampa. У налаштуваннях AniTube перевір версію 1.8.17.
3. При натисканні ОК має одразу з'явитися «AniTube v1.8.17 · Серія N». При наступному відео/автопереході версія з'являється знову; початковий запуск не дає дубля.
4. Перевір швидкість запуску Ashdi в AniTube й AnimeOn, наступну серію, пульт і повернення назад. На ТВ старт більше не чекає сусідні серії; Ashdi явно використовує native HLS. Moon зберігає програмний режим.

Регресії, повний мережевий шлях Ashdi й API AnimeOn перевірені; нове відтворення на фізичних LG/Samsung ще не перевірено. Повідомлення «Таймкоды загружены» досі має невстановлене походження. Makhno не змінювався.

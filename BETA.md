# AniTube beta 1.8.8 — Samsung / LG

Основний плагін залишається 1.8.2. Це оновлення бети для тесту; роботу Moon на справжньому ТВ ще потрібно підтвердити. Android-приставка для цієї схеми не потрібна.

## Оновити

1. У Lampa → Налаштування → Розширення заміни адресу наявного AniTube на коротку: `https://dez955.github.io/a.js`. Вона завжди веде на поточну бету, нова версія підтягується після перезапуску Lampa.
2. Залиш один активний AniTube та повністю перезапусти Lampa. Ключ і стандартна адреса проксі вже вбудовані.
3. Для Moon онови Worker: відкрий https://raw.githubusercontent.com/Dez955/anionline/main/home-proxy/cloudflare-worker.js , скопіюй весь код, далі Cloudflare → Workers & Pages → anitube-proxy → Edit code → заміни код → Deploy. Змінні ACCESS_KEY та EMBED_URL не чіпай. Новий код надсилає заголовок `Accept`, без якого сторінка Moon відповідає HTTP 400. Для сортування оновлення Worker не потрібне. Android-приставка не потрібна, бота оновлювати не треба.

## Сортування

Угорі списку серій є кнопка з двома стрілками. Натискання перемикає «від першої» / «від останньої»; вибір запам’ятовується для наступних відкриттів та інших серіалів. Це спільна логіка для всіх шести джерел. Вона сортує серії поточного сезону й озвучення. Прогрес не змінюється, наступна серія у плеєрі йде за хронологією, навіть коли остання серія показана зверху.

## Перевірити Moon

Відкрий аніме → AniTube → Субтитри · Morys → Плеєр Moon → серія. Під час запуску має бути AniTube v1.8.8. Текст статусу лишається на сторінці серій.

На Samsung і LG плагін сам вмикає для Moon вбудований плеєр із програмною обробкою, бо системному плеєру ТВ не передати потрібні заголовки. Після закриття плеєра твої налаштування повертаються. У налаштуваннях Lampa нічого міняти не треба. Вручну на Samsung Moon підтверджено; автоматичне перемикання ще треба перевірити, на LG Moon не перевірявся.

- AT-M1: не отримано адресу відео/сторінку плеєра. Зазвичай потрібне повідомлення про помилку хмарної частини.
- AT-M3: плеєр повідомив про фатальну помилку відео/сегмента.
- AT-M4: відео не стало готовим за 25 секунд. Плеєр закривається, статус пояснює проблему.

Якщо з’явилася помилка, повідом код і номер серії або надішли фото. Worker читає тільки сторінку Moon. Відео йде напряму на ТВ; Cloudflare-перевірки CDN не обходяться. Із комп'ютера сторінка, список якостей і сегмент відео відповіли успішно, але на ТВ це ще не перевірено.

# ДубльUA 2.0.29 — тестова бета (25.11.2026)

Для тесту в Lampa додай [адресу бети 2.0.29](https://dez955.github.io/anionline/anitube-beta.js?v=2.0.29), вимкни попередній екземпляр ДубльUA й повністю перезапусти Lampa. Коротка адреса `https://dez955.github.io/a.js` лишається на стабільній 2.0.9.

**Нове:** джерело **Kodik** (російські озвучення аніме та серіалів) працює через офіційний API Kodik і відтворюється **у власному плеєрі Kodik** всередині вікна Lampa, як цього вимагають умови Kodik. Російські джерела тепер шукають російською назвою, українські — українською. YummyAnime і Jut-su прибрано.

**Потрібно від власника Worker:** у Cloudflare додати секрет `KODIK_TOKEN` (ключ, виданий Kodik) і розгорнути код `home-proxy/cloudflare-worker.js` (Workers & Pages → anitube-proxy → Edit code → вставити → Deploy). Інші змінні й KV `SYNC` не чіпати. Без цього Kodik пише «у Worker немає ключа Kodik» (HTTP 503) або «потрібне оновлення Worker».

**Перевір на ТВ (це головне):**
1. Налаштування → ДубльUA → **Показувати російські джерела**: увімкни.
2. Відкрий серіал або аніме (наприклад «Кіберпанк: Бігучі по краю»), обери джерело **Kodik**, вибери варіант і озвучення.
3. Натисни на серію: має відкритися плеєр Kodik на потрібній серії. Подивись: **чи керується він пультом** (ОК, стрілки, пауза), **яка реклама** показується і **чи кидає вона на інші сайти** або відкриває нові вікна; чи повертає **Back** до списку серій.
4. Що не працює в цьому режимі (за задумом): прогрес перегляду Lampa, автоперехід на наступну серію, вибір якості Lampa, субтитри плагіна.

Повернення: вимкни бету й увімкни попередню адресу; дані не видаляй.

## Попередня бета 2.0.28 (25.11.2026)

## Попередня бета 2.0.27 (24.11.2026)

Для тесту в Lampa додай [адресу бети 2.0.27](https://dez955.github.io/anionline/anitube-beta.js?v=2.0.27), вимкни попередній екземпляр ДубльUA й повністю перезапусти Lampa. Копія для повернення збережена в [архіві 2.0.26](dev/archive/2026-11-24/2.0.26/anitube.js).

### Ручна перевірка бети 2.0.27

1. На Samsung, LG або Android TV відкрий **Налаштування → ДубльUA → Версія** і переконайся, що встановлена 2.0.27.
2. У **«Показати / сховати джерела»** вимкни й увімкни перший, середній та останній пункти. Перевір, що після натискання **ОК** фокус і прокручування залишаються на місці. Натисни **Назад**, відкрий список знову й перевір збережений стан.
3. У **«Пріоритетність джерел → Фільми»** перемісти останнє джерело на перше місце, підтвердь зміну й перевір фокус. Скасуй ще одне переміщення, перезапусти Lampa й перевір налаштування. Окремо спробуй скинути порядок фільмів і всіх категорій.
4. Відкрий фільм, для якого раніше вибирав інше джерело. Перевір черговість і доступність чипа **«Джерело»** під час пошуку. На тайтлі з недоступним джерелом перевір наступну спробу. Повтори з вимкненим автопереходом.
5. Відкрий фільм і серіал на **UAFilms**. Зафіксуй, чи з’явилися озвучення, чи доповнився список серій, чи запустилося відео та яка версія Lampa й платформа. Достатньо по одній спробі на тайтл. Якщо сервіс показав обмеження, зачекай зазначений час.

Для повернення в локальній копії заміни `anitube.js` файлом з архіву 2.0.26. Публічний відкат бети до 2.0.26 потребує відновлення архівного файлу на GitHub. Параметр версії в адресі сам по собі не виконує відкат.

## Що додано

- DoramaUA у меню «Джерело»: українське озвучення, українські субтитри й автосубтитри окремо. Російські варіанти — лише за перемикачем РОС.
- Фактичні серії кожного перекладу беруться з плеєра сайту. Перед запуском перевіряється відповідність тайтлу, сезону, серії й озвучення. Короткі назви на кшталт «Мо Лі» знаходяться за повним збігом.
- На Samsung/LG для Davidog використовується native HLS; список наступних серій завантажується ліниво. Стеження лишається тільки для аніме на AniTube.

## Що зробити на Samsung/LG

1. Якщо Worker ще не має `/dorama/player`, Cloudflare → Workers & Pages → `anitube-proxy` → Edit code → встав увесь [home-proxy/cloudflare-worker.js](home-proxy/cloudflare-worker.js) → Deploy. Змінні `ACCESS_KEY`, `EMBED_URL` та KV `SYNC` не змінюй. Бот не потребує оновлення, PR/Merge не потрібні. На чинному Worker власника маршрут уже є; повторний Deploy сам по собі не усуне регіональну відмову нижче.
2. Lampa → Налаштування → Плагіни: вимкни A та інші дублікати AniTube, додай або увімкни довгу бета-адресу вище. Повністю закрий і знову відкрий Lampa.
3. Відкрий дораму → AniTube → Джерело → DoramaUA → Озвучення. Перевір запуск, український звук/субтитри, наступну серію та повернення назад.
4. Для повернення на робочу версію вимкни бету, увімкни A й перезапусти Lampa.

## Що перевірено

19 актуальних офлайн-тестів пройшли. Із Mac пройдено живий шлях пошук → тайтл → локально виконаний Worker → точна озвучка/серія → HLS для «Військового кухаря», «Мо Лі» й «Чаші весни». Окремо перевірено відеосегмент H.264/AAC та український WEBVTT.

**Через чинний Cloudflare Worker 08.11 підтверджена регіональна відмова DoramaUA.** Сам маршрут відповідає HTTP 200, але тіло — повідомлення про регіон; новий парсер правильно відхилив його. Отже, хмарний шлях для Samsung/LG наразі не підтвердив працездатність. Повторний Deploy не обходить обмеження країни. Android напряму або вже налаштована домашня приставка — інші наявні шляхи; їх на фізичному пристрої з 2.0.10 ще не перевірено.

Якість і кількість перекладених серій залежать від конкретної доріжки: наявність дорами не означає, що всі серії вже озвучені українською. Публікація бети не означає підтвердження відтворення на ТВ.

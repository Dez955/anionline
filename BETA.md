# AniTube beta 2.0.7 — LG / Samsung / Android

Основний файл лишається 1.8.19. **Worker змінився** (новий маршрут `/sync` для синхронізації стежень). Пошук і відео працюють і без оновлення Worker; для синхронізації потрібні кроки нижче.

**Cloudflare, один раз (лише для синхронізації між своїми ТВ):**
1. Storage & Databases → KV → Create: назва `anitube-sync`.
2. Workers & Pages → anitube-proxy → Settings → Bindings → Add → KV namespace: Variable name `SYNC` (великими), namespace `anitube-sync`.
3. Edit code → вставити весь `home-proxy/cloudflare-worker.js` з цього репозиторію → Deploy. `ACCESS_KEY` і `EMBED_URL` не чіпати.

1. Залиш один активний AniTube: https://dez955.github.io/a.js або https://dez955.github.io/anionline/anitube-beta.js?v=2.0.7
2. Повністю перезапусти Lampa. У налаштуваннях AniTube має бути «Версія 2.0.7».
3. **Зірочка на картці**: окрема кнопка в рядку кнопок картки (перед «⋯»). Сіра — не стежу, після натискання зелена. Вона лише додає тайтл у список, нічого не відкриває. Повторне натискання знімає стеження.
4. **Зірочка вгорі** поряд із дзвіночком: «Мої стеження» з постерами, назвою, лічильниками «Субтитри: N · Озвучення: N» або останньою новою серією з датою. ОК відкриває сторінку тайтла Lampa (там «Дивитися → AniTube» і вибір джерела). Довге ОК: «Що чекати» (будь-що / субтитри / озвучення для цього аніме), «Відкрити сторінку», «Прибрати».
5. **Дзвіночок угорі Lampa**: вкладка «AniTube» зі сповіщеннями про нові серії; перевірка AniTube кожні 5 хвилин, поки Lampa відкрита і не йде відео. Перша перевірка лише запам'ятовує наявні серії.
6. **Налаштування → AniTube**: «Стеження: типово для нових зірочок» (що чекати від щойно доданих; для кожного аніме міняється у списку) і «Мої стеження».
7. **Зірочка лише для аніме.** На картці звичайного серіалу, фільму чи західного мультфільму зірочка нічого не додає, а пише «AniTube стежить лише за аніме.» (для серіалу ще підказка про дзвіночок Lampa на картці). Якщо на картці нема жанрів, тайтл додається, як раніше. Уже додані раніше не-аніме прибираються повторним натисканням зірочки або через «Мої стеження» → «Прибрати».
8. **Нове в 2.0.6: стійкість до збоїв мережі.** Запит до Worker, що не отримав відповіді (обрив, таймаут), повторюється один раз. Перевірка нових серій — кожні 5 хвилин замість 20 і не працює, поки відкрите відео. Причина змін: на деяких домашніх каналах губиться частина пакетів до Cloudflare (Worker, AniTube, сервери Moon), тоді пошук пише «помилка мережі», а Moon дає AT-M4. Ashdi йде іншим шляхом і працює. Повністю це плагін виправити не може.
9. Ручна назва в «Пошуку» окрема для кожного джерела; «Знижувати якість Moon» типово вимкнено; список «Джерело» згруповано.
10. **Нове в 2.0.7: синхронізація «Моїх стежень».** Налаштування → AniTube → «Код синхронізації стежень»: однаковий код (від 6 латинських літер, цифр чи дефісів) на своїх ТВ — один список. Далі саме: при запуску, після зірочки й раз на 30 хв; є кнопка «Синхронізувати стеження зараз». Передається лише список, лічильники й сповіщення на кожному ТВ свої. Без коду нічого не надсилається.
11. **Нове в 2.0.7: назви в списку з AniTube.** Тайтл, що лишився з японською назвою картки, сам отримує назву сторінки AniTube при наступній перевірці (не частіше разу на 6 год).

Перевірки: регресії й тести стеження на збережених даних AniTube. На фізичних LG/Samsung 2.0.7 ще не перевірена; синхронізація перевірена на стенді з імітацією сховища, не на справжньому Cloudflare KV; фоновий пошук тайтла на живому AniTube не перевірявся.

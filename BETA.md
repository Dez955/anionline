# AniTube beta 2.0.11 — джерела й перше відкриття (08.11.2026)

> **2.0.16 (опублікована бета): плагін тепер «ДубльUA», мітки субтитрів за реальними файлами.** Адреса після публікації: `https://dez955.github.io/anionline/anitube-beta.js?v=2.0.16`. Перевірити: DoramaUA «Ідеальна робота» має показувати «Субтитри (укр.)» (з РОС «Субтитри (укр. + рос.)»), а не «Субтитри (рос.)».

> **2.0.15 (бета): KinoPub лише на Android.** Адреса: `https://dez955.github.io/anionline/anitube-beta.js?v=2.0.15`. З серверів Cloudflare kinopub.me показує захист Anubis і хибний пошук, тому на Samsung/LG джерела KinoPub немає (Worker для нього не потрібен, повторний Deploy не треба). На Android: картка → AniTube → чип «Джерело» → KinoPub; перевір «Дюна» (2021) — «Український дубляж» з українськими субтитрами, «Доктор Ікс» — «Оригінал + субтитри». Російські озвучення — лише з перемикачем РОС.

Канали розділені: коротка адреса **https://dez955.github.io/a.js** закріплена на незміненій робочій **2.0.9** (`old/anitube-2.0.9.js`). Досліди й нові можливості — тільки за довгою бета-адресою:

**https://dez955.github.io/anionline/anitube-beta.js?v=2.0.11**

Старий файл `anitube.js` лишається 1.8.19. Не вмикай одночасно дві адреси AniTube: для перевірки бети вимкни A, увімкни довгу адресу й повністю перезапусти Lampa. Дані та список стежень видаляти не потрібно.

## Нове у 2.0.11

- Налаштування → AniTube → перший пункт **«Показати / сховати джерела»**. Натискання на джерело перемикає «Показувати / Приховано». Приховане прибирається з меню й автоматичного пошуку. Збережені вибори не видаляються.
- Відомі збережені сторінки AniTube, зокрема з дзвіночка, відкриваються без повторного пошуку та очікування додаткових назв TMDB/AniList.
- Очікування картинок/дат серій TMDB обмежене 500 мс замість 5 секунд; за повільної відповіді вони можуть тимчасово не показуватися.
- 20 актуальних офлайн-тестів пройшли. Швидкість на фізичному Samsung ще треба перевірити. Для 2.0.11 нового Deploy Worker не потрібно, серверний код не змінено.

## Що додано

- DoramaUA у меню «Джерело»: українське озвучення, українські субтитри й автосубтитри окремо. Російські варіанти — лише за перемикачем РОС.
- Фактичні серії кожного перекладу беруться з плеєра сайту. Перед запуском перевіряється відповідність тайтлу, сезону, серії й озвучення. Короткі назви на кшталт «Мо Лі» знаходяться за повним збігом.
- На Samsung/LG для Davidog використовується native HLS; список наступних серій завантажується ліниво. Стеження лишається тільки для аніме на AniTube.

## Що зробити на Samsung/LG

1. Якщо Worker ще не має `/dorama/player`, Cloudflare → Workers & Pages → `anitube-proxy` → Edit code → встав увесь [home-proxy/cloudflare-worker.js](home-proxy/cloudflare-worker.js) → Deploy. Змінні `ACCESS_KEY`, `EMBED_URL` та KV `SYNC` не змінюй. Бот не потребує оновлення, PR/Merge не потрібні. На чинному Worker власника маршрут уже є; повторний Deploy сам по собі не усуне регіональну відмову нижче.
2. Lampa → Налаштування → Плагіни: вимкни A та інші дублікати AniTube, додай або увімкни довгу бета-адресу вище. Повністю закрий і знову відкрий Lampa.
3. Відкрий дораму → AniTube → Джерело → DoramaUA → Озвучення. Перевір запуск, український звук/субтитри, наступну серію та повернення назад.
4. Для повернення на робочу версію вимкни бету, увімкни A й перезапусти Lampa.

## Що перевірено

19 актуальних офлайн-тестів пройшли. Із Mac пройдено живий шлях пошук → тайтл → локально виконаний Worker → точна озвучка/серія → HLS для «Військового кухаря», «Мо Лі» й «Чаші весни». Окремо перевірено відеосегмент H.264/AAC та український WEBVTT.

**Через чинний Cloudflare Worker 08.11 підтверджена регіональна відмова DoramaUA.** Сам маршрут відповідає HTTP 200, але тіло — повідомлення про регіон; новий парсер правильно відхилив його. Отже, хмарний шлях для Samsung/LG наразі не підтвердив працездатність. Повторний Deploy не обходить обмеження країни. Android напряму або вже налаштована домашня приставка — інші наявні шляхи; їх на фізичному пристрої з 2.0.10 ще не перевірено.

Якість і кількість перекладених серій залежать від конкретної доріжки: наявність дорами не означає, що всі серії вже озвучені українською. Публікація бети не означає підтвердження відтворення на ТВ.
